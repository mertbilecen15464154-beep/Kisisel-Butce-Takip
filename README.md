# Kisisel-Butce-Takip
# 📊 Kişisel Bütçe ve Harcama Takip Uygulaması

Kullanıcıların gelir ve giderlerini kolayca takip etmelerini, aylık bütçelerini analiz etmelerini ve finansal hedeflerini yönetmelerini sağlayan modern, hızlı ve duyarlı (responsive) bir web uygulaması.

---

## 🚀 Öne Çıkan Özellikler

- 💳 **Gelir ve Gider Takibi:** Kategori bazlı harcama ve gelir ekleme/silme işlemleri.
- 📈 **Grafik ve Bütçe Analizi:** Bütçe özetini görselleştiren etkileşimli arayüz.
- 📱 **Tam Mobil Uyumluluk:** Mobil, tablet ve masaüstü cihazlar için optimize edilmiş Tailwind CSS tasarımı.
- ⚡ **Hızlı ve Dinamik UI:** JavaScript (ES6+) ile akıcı kullanıcı deneyimi.
- 🛠️ **Backend / Server Entegrasyonu:** Express.js tabanlı RESTful API yapısı ve veri yönetimi.

---

## 🛠️ Kullanılan Teknolojiler

- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+)
- **Backend:** Node.js, Express.js
- **Veri / Ortam:** JSON / SQL Entegrasyonu, npm
